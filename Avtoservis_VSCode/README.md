# Автосервис

Учебная программа для работы с данными автосервиса на Python и SQLite. Сервер и сторонние библиотеки не нужны. При первом запуске автоматически создаётся файл `avtoservis.db` и добавляются примеры данных.

## Запуск в Visual Studio Code

1. Установите Python 3.10 или новее.
2. Откройте в VS Code папку `Avtoservis_VSCode`.
3. Откройте файл `main.py`.
4. Нажмите кнопку запуска Python-файла или откройте терминал VS Code и выполните:

   ```bash
   python main.py
   ```

   Если команда `python` не работает в Windows, попробуйте `py main.py`.

5. Выберите пункт меню цифрой. База данных хранится рядом с программой в `avtoservis.db`.

## Возможности

- клиенты, автомобили, сотрудники и услуги;
- создание, просмотр и удаление заказов;
- изменение статуса заказа и запись истории изменений;
- поиск заказов;
- расчёт стоимости услуг и статистика;
- внешние ключи, ограничения целостности, представление `order_summary`;
- транзакции SQLite через контекстный менеджер.

## Структура

- `main.py` — программа и создание базы данных;
- `avtoservis.db` — создаётся автоматически при запуске;
- `README.md` — инструкция.

Важно: этот вариант рассчитан на запуск без отдельного сервера и использует SQLite. Если в задании обязательно требуется именно Microsoft SQL Server и хранимые процедуры T-SQL, такой вариант не заменяет SQL Server-версию полностью.
